# 鸡蛋期货(JD) 量化系统 · 模拟盘运行指南

> 用途：把上一阶段的回测策略落到 **模拟盘（Paper Trading）**，用真行情滚动验证，
> 不发实盘。全过程基于 `/workspace/jd2611_quant` 的代码与数据。
> **本指南不构成投资建议。**

---

## 0. 为什么先跑模拟盘

1. 回测结论是"研究性为正"（长历史主力连续，70/30 样本外 +15.85%），但**回测 ≠ 实盘**：
   信号基于收盘价、假设次日开盘成交、忽略部分执行摩擦。
2. 模拟盘用**每天的新收盘数据**推进，检验策略在真实行进中的表现与盘中止损执行情况。
3. 目标不是"模拟出更高收益"，而是**证明流程能闭环 + 参数在新增数据上不快速失效**。

## 1. 环境与核心参数

- Python + akshare（已装）；工作目录 `/workspace/jd2611_quant`。
- 主力连续数据：`data/jd_main_hist.csv`（2014-01 ~ 今，akshare/新浪，未复权）。
- **当前默认策略参数**（`config.py`）：

| 参数 | 值 | 含义 |
|------|----|------|
| `RISK_PER_TRADE` | 2% | 单笔最大风险占资金 |
| `ATR_STOP_MULT` | 2.5 | 初始硬止损 = 开仓价±2.5×ATR |
| `TRAIL_STOP_TRIGGER` | 10% | 盈利达开仓价10%启动移动止损 |
| `TRAIL_STOP_ATR` | 4.0 | 移动止损用 4×ATR 跟踪 |
| `TREND_MA / TREND_MA_MAJOR` | 15 / 60 | 中周期/大周期趋势门控 |
| `SIGNAL_THRESHOLD` | 3 | 多信号共振开仓阈值 |
| `MIN_TRADE_INTERVAL` | 6 | 平仓后冷却 bar 数 |

合约：大商所鲜鸡蛋，5 吨/手，1 点=10 元/手，报价元/500kg；保证金率约 12%，
单边手续费 2 元/手，滑点 1 跳（1 跳=10 元/手）。

## 2. 每日例行流程（收盘后执行）

每天收盘后，在 `/workspace/jd2611_quant` 顺序执行：

### Step 1 · 更新数据
```
python fetch_history.py
```
拉取/追加最新主力连续日线，输出 `data/jd_main_hist.csv`。
若无新数据或网络失败，脚本会如实报"今日未更新"——**不要用旧数据硬跑当新信号**。

### Step 2 · 读单（看当前持仓与是否有待执行信号）
```
python paper_signal.py
```
输出含义：
- `当前持仓`：空仓 / 多/空单 N 手、开仓价、当前止损（含移动止损标记）。
- `待执行信号`：仅在**同时满足三条件**时才报——① 最后一个交易日 `signals[-1]` 收盘
  有信号；② 当前**空仓**；③ 距最近离场已满足冷却期（≥ 6 个交易日）。三者缺一即报
  "无"。此判定与回测端成交条件逐一对齐，**冷却期内的反向信号不会被误报为待执行**
  （回测同样不会在冷却期内成交）。
- `最近平仓`：最近一笔的区间、方向、净盈亏、离场原因(`hard_stop`/`move_stop`/`flip`)。

### Step 3 · 有信号则下单（次日开盘执行）
- 执行价格：**次日开盘价**（模拟盘用真实次日开盘价或近似）。
- 方向/仓位按第 3 节「以损定仓」倒推手数。
- 记录仓位于模拟盘日志（第 6 节模板）。

### Step 4 · 有持仓则每日核对止损/移动止损
- 多头：盘中价 ≤ 止损价 → 按止损价离场，原因记 `hard_stop` 或 `move_stop`。
- 移动止损：盈利达开仓价 10% 后用 4×ATR 逐步抬/压止损。可在收盘后对比
  `paper_signal.py` 的"当前止损"是否已更新。

### Step 5 · 存档与自动汇总
每日 16:30 的定时任务会自动跑 `run_long.py` + `walk_forward.py` + `visualize_main.py`
并汇报 70/30 样本外与滚动样本外表现。**当两个样本外口径一正一负或转弱时，任务会明确
提示——把它当作暂停/复核的信号，而不是忽视。**

## 3. 以损定仓（仓位公式）

```
风险额      = 当前资金 × RISK_PER_TRADE        # 默认 2%
止损距离    = 当前 ATR × ATR_STOP_MULT         # 点子数（可用 paper_signal / 策略内部 ATR）
每手风险额  = 止损距离(点) × 合约乘数(10)      # 元/手
开仓手数    = 整手向下取整 ( 风险额 / 每手风险额 )，最小 1 手
```
示例：资金 100 万、ATR=50、止损 2.5×50=125 点
→ 每手风险 125×10=1,250 元 → 风险额 20,000 元 → **16 手**。
> 检查：16 手 × 125 点 ×10 = 20,000 ≈ 恰好那 2%，符合"敢重仓位但单笔损失锁死"。

下单后再确认保证金充足：手数×开仓价×乘数×12% ≤ 可用资金。

## 4. 止损与移损执行纪律（不扛单）

| 规则 | 触发 | 操作 |
|------|------|------|
| 初始硬止损 | 开仓即挂 ATR×2.5 | 无条件市价离场，不商量 |
| 移损启动线 | 浮盈 ≥ 开仓价 10% | 启动移动止损 |
| 移动止损 | 止损价按 ATR×4 跟进 | 触及即离场，落袋大趋势 |
| 平仓冷却 | 离场后 6 个交易日 | 此间不开反向新仓 |
| 信号翻转 | 出现相反方向信号 | 平掉现持仓（`flip`） |

凡离场都记原因：`hard_stop`（硬止损）/ `move_stop`（移损跟保护）/ `flip`（信号翻转）。

## 5. 合约换月处理（主力连续）

- 系统使用**主力连续**（Vol/OI 最大合约切换拼接），因此每日读单天然在"当前主力"上。
- 实盘上周旋节点：当持仓合约临近交割或主力切换，需**平移换仓**到新主力（如 JD2611→JD2612）。
- 模拟盘建议：每月的第一个交易日检查主力是否切换；若切换且仍有持仓，按两合约价差
  平移记录，并把因价差产生的盈亏单独记账，避免污染策略绩效。

## 6. 模拟盘记录表模板（建议 `paper_log.csv`）

| 字段 | 说明 |
|------|------|
| open_date / open_px | 开仓日 / 开仓价（次日开盘） |
| direction / lots | 方向 / 手数 |
| initial_stop | 初始硬止损价 |
| trail_start_date | 移损启动日（若有） |
| close_date / close_px | 平仓日 / 平仓价 |
| exit_reason | hard_stop / move_stop / flip / 移仓价差 |
| fee_slip | 手续费+滑点成本（可合并） |
| pnl_net | 净盈亏（含成本） |
| note | 备注 |

> 目的：与 `output/trades.csv`（回测）**逐笔对齐对比**，看模拟偏差的来源
> （滑点、换月、执行时机），而不是只看总收益。

## 7. 复盘要点（建议每周一次）

1. **模拟 vs 回测逐笔差额**：主要来自滑点/换月，还是参数在新增数据上漂移？
2. **连亏是否触发过冷却期**、止损是否都被执行到位（有无"犹豫"）？
3. 对比每日任务的 **70/30 样本外** 与 **滚动样本外**：两者是否持续同向？
4. 若两个样本外口径连续一周背离或转负，暂停模拟，回到长历史重做参数再续。

---

## 8. 风险与边界（务必读）

- 主力连续**未复权**，切换点有轻微失真；全部数据来自公开源，未做第三方核对。
- 参数仍敏感：默认配置是长历史 70/30 定参结果，**不代表对任何未来行情有效**。
- 模拟盘胜率天然只有 35% 上下，利在盈亏比（PF≈1.9）；单一商品单策略的敞口集中，
  不建议直接按此模拟仓上实盘，宜先多品种小仓位磨炼流程。
- 一切为研究目的；若打算实盘，请由正规期货账户、自主风控、必要时专业意见兜底。
