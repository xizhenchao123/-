# JD2611 半量化研判系统

鸡蛋期货 JD2611 盘中/收盘半量化研判系统（纯前端单页应用，数据源：新浪财经行情接口 JSONP）。

- 在线访问：https://xizhenchao123.github.io/-/
- 手机浏览器直接打开即可，无需安装，流量即可访问
- 持仓跟踪等数据保存在本机 localStorage，不同设备相互独立
- 本系统仅供研判参考，不构成任何交易指令

## 功能

- 盘中实时研判（11 项模板）：固定五步逻辑 + 鹰眼一票否决 + 盈亏比过滤
- 收盘复盘（6 项模板）：当日全周期归档与次日观察位
- 机会评级 A/B/C/D：基本面不支持最高 C；多周期矛盾不得高于 C；RR<1.5R 不得高于 B
- 持仓跟踪：入场/止损/状态/跨日连续亏损清零

## 数据说明

实时数据通过新浪财经公开行情接口（JSONP）获取，1 分钟/5 分钟/60 分钟/日线多周期。
若接口失效，系统会如实标注数据缺失并降级处理，不编造数据。
